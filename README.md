# tacheo-site

The website for **Tacheo**, the cave survey instrument that checks its own work, and its free companion software **Tacheo Topside** and **CartoTable** (cave survey data, cartography and GIS).

- `index.html` (the home page: a hub to every page), `download.html` (every download: Windows, Mac, Android, iPhone), `phone.html` (the phone app) and the other pages: the site (GitHub Pages, from the root of `main`)
- `assets/`: styles, images, and `reserve.js` (the Reserve and Message forms, which post to Sully's Google Apps Script)
- **Releases**: the Topside downloads. The site links to `releases/latest/download/<file>`, so the newest release is always what people get.
